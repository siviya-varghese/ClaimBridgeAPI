#Claim Bridge API

Claim Bridge API provides backend support for calculating and storing insurance premium details based on user data and occupation risk factors.
It exposes RESTful endpoints for fetching occupation details and saving user information with calculated monthly premiums.

#Setup & Run Instructions (ASP.NET Core Web API)
1. Prerequisites
Before running the Claim Bridge API, ensure you have the following installed:
  * Dot NET 8.0 SDK
  * PostgreSql
  * Visual Studio 2022
2. Clone the Repository
3. Configure Database Connection
4. Run the API - Set ClaimBridge as startup project
